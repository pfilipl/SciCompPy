
# XRF Spectra ROI Definer

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)]

*SciCompPy project application* for defining energetic regions of interest (ROIs)
for X-ray Fluorescence spectra analysis.

## Authors

- Filip J. Baran

## Dependecies
- python = ">=3.14.3,<3.15"
- xraylib = ">=4.2.1,<5"
- pyside6 = ">=6.11.1,<7"

## Usage

```bash

python main.py
```
